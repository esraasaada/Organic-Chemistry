# سجل التحقق — Organic Chemistry Universe 3.0

## اختبارات الوظائف والمحركات

يُشغّل `npm test` اختبارات Vitest وReact Testing Library في jsdom. تغطي:

- بنك80 سؤالاً: التفرد، توزيع10/درس، الإجابات والتفسيرات والمستويات والأنواع.
- حفظ ذرات C/H/O عبر الوقود وقيم الأكسجين، وحصيلة الإضافة والأسترة.
- اتزان الأسترة وقيمة K الافتراضية، وأثر الماء، وعدم تغير النهاية بالحفاز.
- متفاعل محدِّد، وبروم فائض، وجرعة كاشف صفر، ومدخلات غير صالحة وأزواج ذوبانية غير موثقة.
- كل نماذج الجزيئات وتكافؤاتها وصيغها، وتمييز المتماكبات وكشف المجموعات.
- بناء إيثانول يدوياً عبر الواجهة، وعدم اكتساب الشارة من نموذج جاهز.
- ثمانية مسارات تجارب كاملة: تجهيز، إضافة مواد، تشغيل، إجابة، دفتر، تقرير، واستدعاء إنجاز صحيح.
- إسقاط أدوات ومواد فعلياً عبر أحداث Drag/Drop، ومنع الإضافة المبكرة، والإيقاف والاستئناف.
- حفظ الفرضية والتقارير واستعادتها، والتعامل مع JSON تالف.
- قواعد المساعد حسب التجهيز والإجابات والمستوى.
- أنشطة الألعاب: بناء ثلاث تراكيب، ثلاثة أقفال متسلسلة، أربع مطابقات، تحديد موضع المجموعة قبل تصنيفها، والسحب الفعلي.
- الرسوم المرتبطة بـn وباختيار المجموعة الوظيفية، وأنشطة DOK للدروس الثمانية.
- الاختبارات الكاملة والتنقل، وحفظ الاسم وتفضيلات العرض والوضع النهاري.
- ترحيل تقدم الإصدار السابق دون فقدان اسم أو شارة أو درجة.
- البديل الجزيئي SVG ومنع تجاوز تكافؤ H، واستدعاء بديل المختبر عند فشل WebGL.

`npm run typecheck` يفحص TypeScript، و`npm run build` ينشئ حزمة الإنتاج. لا تعتمد الاختبارات على تسجيل حساب أو أسرار.

## فحوص بيئة التنفيذ

- إعادة محاولة المعاينة: فشل `sites-preview` بخطأ `relay could not open browser port 4173: timed out waiting for relay readiness`.
- محاولة فتح الموقع المنشور عبر المتصفح: فشل موصل التحكم برسالة `Browser Use could not read requirements`.
- فحص HTTP من بيئة التنفيذ: حُجب الاتصال بـgithub.io برسالة `CONNECT tunnel failed, response 403` من مسار الشبكة. هذا لا يثبت تعطل موقع GitHub Pages.

لذلك **لم يُتحقق بصرياً** من الصورة النهائية على هاتف أو حاسوب، أو إخراج PDF، أو رسم WebGL الفعلي وأدائه. اختبارات المشاهد تثبت البدائل وإدارة الواجهة، لا جودة GPU. واجهات اللمس والكاميرا مصممة ومبرمجة لكن تظل اختبارات اللمس الفعلية مطلوبة على الجهاز المستهدف.

## فحص العرض قبل التقديم الجامعي

1. افتح الصفحة الرئيسية على هاتف وحاسوب، وبدّل الوضع النهاري والحركة والخط.
2. افتح المختبر ودوّر الكاميرا وقرّبها، واختر الطاولة والخزانة بأزرار الكاميرا.
3. جرّب السحب ثم أزرار الإضافة، وحدد وعاءً، واضبط الكميات، وشغّل وأوقف واستأنف.
4. قارن جرعات البروم والأكسجين، ثم تحقّق من معادلة الإضافة ونموذج الناتج.
5. قارن الأسترة مع الحفاز وبدونه عند نهاية العرض؛ يجب تساوي الاتزان النهائي.
6. أكمل التقويم وسجّل الفرضية والاستنتاج، واحفظ تقريراً واطبعه/احفظ PDF.
7. افتح التقرير المحفوظ بعد إعادة تحميل الصفحة، وتحقق من تطابق إعداداته القديمة.
8. جرّب البديل الثنائي ثم بناء الإيثانول والتماكب وتلوين المجموعات والألعاب.

حالة النشر النهائية تؤخذ من GitHub Actions لمراجعة commit المنشور؛ نجاح البناء وحده لا يعني نجاح النشر أو فحص المتصفح.
