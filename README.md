# عالم الكيمياء العضوية | Organic Chemistry Universe 3.0

**إعداد المعلم: عمر فرج الله** — منصة عربية RTL للمرحلة الثانوية، بمختبر افتراضي وألعاب ودروس وتقييم. React 19 + TypeScript + Vite + Three.js، دون حساب أو API مدفوع.

رابط GitHub Pages: https://esraasaada.github.io/Organic-Chemistry/

## ما الجديد في 3.0؟

### المختبر أولاً

- بيئة Three.js بأثاث وخزائن وأرفف وطاولة وحامل أنابيب وزجاجيات وماصة ومخبار وميزان وسخان تعليمي. ظلال وإضاءة ومواد شفافة وانعكاس إضاءة إجرائي على الحواسيب؛ أداء أخف على الهواتف.
- تدوير الكاميرا وتقريبها وتحريكها بالفأرة/اللمس، وأزرار للوصول إلى الطاولة والخزانة. اختيار أداة داخل المشهد أو من قائمة متاحة بلوحة المفاتيح.
- نقل الأدوات بالسحب والإفلات أو النقر. تحديد وعاء وإضافة العينة والكاشف بالكميات المحددة. تبقى الزجاجيات فارغة حتى إضافة مادة مناسبة؛ لا يظهر سائل في تجارب الغازات.
- تحقق من اكتمال التجهيز، وتشغيل/إيقاف مؤقت/استئناف/إعادة، ومتغيرات مرتبطة بمحركات الحساب. زمن العرض تعليمي، وليس زمن تفاعل مقاساً.
- ثماني تجارب كاملة: الاحتراق، ماء البروم، الإضافة، الأسترة والاتزان، الذوبانية، الخواص الفيزيائية، البلمرة، والمجموعات الوظيفية. لكل تجربة هدف وأدوات وإرشادات ومدخلات ونتائج وتفسير وثلاثة أسئلة وتقرير.
- مساعد مختبر مرسوم تفاعلياً؛ رسائله تستجيب للأدوات والمواد الناقصة وأخطاء التجهيز ومرحلة العرض والإجابات. يطرح أسئلة ويقدم تلميحات وتوصيات حسب المستوى. يعمل بقواعد محلية، دون نموذج AI خارجي.
- دفتر محلي مستقل لكل تجربة: الاسم والفرضية والمتغيرات والخطوات والملاحظات والنتائج والاستنتاج. تقارير محفوظة بلقطة من الإعدادات والنتائج والتقويم، ورسوم بيانية للطباعة عند وجود بيانات. تنزيل نسخة JSON من الدفتر، والطباعة/الحفظ PDF من نافذة المتصفح.

### البناء الجزيئي والتعلم

- دعم C/H/O/N/F/Cl/Br/I في النطاق المتعادل المعتاد، وروابط أحادية وثنائية وثلاثية، وإزالة ذرات وروابط وفحص التكافؤ.
- مكتبة 25 تركيباً، وتعرف بالاتصال ورتب الروابط، وصيغة Hill وقائمة اتصال بنائي وتحديد وتلوين المجموعات الوظيفية ومقارنة المتماكبات.
- تحدي بناء إيثانول يدوي حقيقي؛ تحميل النموذج الجاهز لا يكسب الشارة. زوايا موثوقة للميثان والإيثين والإيثاين والبنزين؛ بقية الهندسات موسومة كتقريبية.
- ثمانية دروس أصلية مع أمثلة محلولة ورسوم تتغير مع المدخلات وأنشطة SEN وأسئلة DOK1/2/3 وتجارب مرتبطة واختبار ختامي.
- بنك 80 سؤالاً مع تفسيرات، واختبارات قبلية وبعدية واختبارات دروس. المطابقة والترتيب ضمن البنك اختيار الإجابة الصحيحة؛ ألعاب المطابقة والبناء تستخدم سحباً وإفلاتاً فعلياً مع بديل بالنقر.
- ست ألعاب 3.0: بناء الجزيئات، غرفة الهروب، محقق المجموعات، توقع التفاعلات، مطابقة الجزيئات، وبطولة الكيمياء. مؤقت اختياري ونقاط وشارات وتفسير.
- واجهة ليلية ونهارية وخلفية جزيئية ثلاثية الأبعاد وشريط تقدم، وخيارات تكبير الخط والتباين وتقليل الحركة، مع بدائل SVG/ثنائية الأبعاد عند تعذر WebGL.

## التشغيل

Node.js 22 أو أحدث:

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

افتح `http://localhost:5173/Organic-Chemistry/`. المخرجات في `dist/`، والمشاهد الثقيلة حزم مستقلة تُحمّل عند الحاجة.

## التخزين والتقدم

- التقدم في `ocu-progress-v1` مع ترحيل الإصدار السابق تلقائياً إلى مخطط v3. لا تُحذف أسماء الطلاب أو نتائجهم أو شاراتهم. تُرحّل تجربة المقارنة القديمة إلى تجربة الخواص الفيزيائية.
- الدفتر والتقارير في `ocu-notebook-v3`؛ حد احتفاظ 80 تقريراً محلياً لتقليل امتلاء التخزين.
- إنجاز الدرس يتطلب 70% في اختبار الدرس. حفظ إنجاز التجربة يتطلب إكمال العرض والأسئلة وإدخال الاسم والفرضية والاستنتاج، مع حفظ النتيجة الفعلية ولو كانت منخفضة.
- نسبة الرحلة = الدروس الثمانية والتجارب الثماني المكتملة ÷ 16. توصيات الاختبار للمفاهيم التي تقل نتيجتها عن70% في أسئلته.
- البيانات تبقى في هذا المتصفح ولا تتزامن بين الأجهزة، وقد تُحذف بمسح بيانات الموقع. يظهر تنبيه عند تعذر التخزين. النسخة JSON للتصدير وليست خدمة سحابية؛ لا توجد واجهة استيراد في هذا الإصدار.

## الدقة وحدود النماذج

تفاصيل المعادلات والافتراضات في [النماذج العلمية](docs/SCIENTIFIC_MODELS.md).

هذه محاكاة تعليمية وليست تجربة حقيقية أو نتائج قياس أو إرشادات لتنفيذ تجربة مخبرية. الأدوات رقمية، والتدريجات والميزان توضيحيان. الجسيمات المتحركة تمثل المزج ولا تثبت انطلاق غاز.

نموذج الأسترة يستخدم **K=4 افتراضية** للمقارنة المثالية، وليس ثابتاً تجريبياً لأي حمض وكحول. الحفاز لا يغير الاتزان النهائي. لا نختلق اعتماداً على الحرارة؛ لذلك التجربة تثبت الحرارة ولا تعرض منزلقاً حرارياً مضللاً. إزالة الماء تخص الماء الابتدائي قبل الاتزان فقط.

الذوبانية وصفية للأزواج المدعومة، وأزواج لا تتوفر بياناتها موضحة كغير متاحة. الخواص الفيزيائية بيانات مرجعية مدورة بروابط PubChem. لا تُستنتج قيم ذوبانية أو كتلة من ألوان الرسم.

البوليمر مقطع قصير هندسته تقريبية ونهاياته مشبعة بالهيدروجين للتوضيح؛ معادلة وحدة التكرار لا تصف مجموعات النهاية. لا يوجد محرك طاقة أو حركية جزيئية أو تسمية عامة لكل جزيء. فحص التكافؤ لا يغطي الأيونات والجذور الحرة وفرط التكافؤ؛ كشف المجموعات والتعرف لهما نطاق محدد.

## GitHub Pages وCI

المسار الأساسي `/Organic-Chemistry/` والتوجيه عبر hash يدعمان تحديث الصفحة دون قواعد خادم. مثال رابط تجربة مباشرة: `#lab?experiment=ester`.

من Settings → Pages اختر GitHub Actions. المسار `.github/workflows/pages.yml` يتحقق من TypeScript والاختبارات والبناء على PR وmain، ولا ينشر من PR. بعد الدمج إلى main تُرفع الحزمة وتُنشر عبر Pages. يتطلب النشر `pages:write` و`id-token:write` فقط في مهمة النشر؛ مرحلة الاختبار تقرأ المحتوى ولا تكتب المستودع.
