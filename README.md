# عالم الكيمياء العضوية | Organic Chemistry Universe

منصة عربية تفاعلية لطلاب المرحلة الثانوية، **إعداد المعلم: عمر فرج الله**. تطبيق ثابت يعمل دون حساب أو خادم، مبني بـ React 19 وTypeScript وVite وThree.js، بواجهة RTL متجاوبة.

## التشغيل والتحقق

يتطلب Node.js 22 أو أحدث.

```bash
npm ci
npm run dev
npm test
npm run build
```

العنوان المحلي الافتراضي: `http://localhost:5173/Organic-Chemistry/`، ومخرجات الإنتاج في `dist/`.

## الوظائف المنفذة

- ثمانية دروس، أهداف وأنشطة تمهيدية وشروح وتطبيقات، مع مسارات مبتدئ/SEN ومتوسط ومتقدم.
- بنك 80 سؤالاً أصلياً، عشرة لكل درس، مع تفسيرات ومستويات DOK 1/2/3. أنماط المطابقة والترتيب والتفسير والتحليل منفذة عبر اختيار الإجابة/التفسير الصحيح، وليست سحباً وإفلاتاً أو تصحيح نص حر.
- اختبار قبلي وبعدي من 16 سؤالاً (سؤالان لكل درس)، واختبارات دروس. يتغير ترتيب الاختبار وعينته عند إعادة المحاولة. المبتدئ يجيب بخيارين وأسئلة DOK1، والمتوسط حتى DOK2، والمتقدم حتى DOK3.
- توصيات محلية واضحة: الدروس التي تقل نتيجتها عن 70% تُقترح للمراجعة. اعتماد إكمال الدرس عند 70% فأكثر. لا اتصال بخدمة ذكاء اصطناعي خارجية.
- خمس محاكاة: الاحتراق وتغير الأكسجين، ماء البروم، إضافة H₂/Br₂، الأسترة من أربع مجموعات اختيار، ومقارنة بيانات مرجعية. لكل تجربة هدف وأدوات وخطوات ونتائج وثلاثة أسئلة وتقرير طباعة.
- بناء جزيئات C/H/O وروابط أحادية وثنائية وثلاثية، وفحص التكافؤ والصيغة، واختيار/حذف الذرات والروابط، وتدوير وتكبير. مكتبة التعرف تدعم الميثان والإيثين والإيثاين والإيثانول والبنزين عبر اتصال الذرات ورتب الروابط، وليس الصيغة وحدها. Three.js في حزمة مستقلة تُحمّل عند فتح المختبر. بديل SVG ثنائي الأبعاد تلقائي عند فشل WebGL أو يدوي.
- ست ألعاب معرفية تعمل فعلياً بنقاط وشارات وتغذية راجعة ومؤقت اختياري. الألعاب الخمس الأولى أربعة أسئلة لكل لعبة؛ النهائي ستة أسئلة متدرجة من البنك.
- لوحة تقدم وشارات وسجل نتائج واسم طالب، مع حفظ محلي وإعادة الاسترجاع. تقارير قابلة للطباعة أو الحفظ PDF من نافذة الطباعة.
- تقليل الحركة وتكبير الخط وزيادة التباين، واحترام إعداد تقليل الحركة في النظام، وتنقل بلوحة المفاتيح وتخطيط مناسب للهاتف.
- قسم تطبيقات حياتية يتضمن البتروكيماويات في الإمارات ومراجع للتوسع.

## النشر على GitHub Pages

`vite.config.ts` يحدد `base: '/Organic-Chemistry/'`. التنقل بالأجزاء `#lessons` و`#lab` وغيرها، ولذلك إعادة تحميل رابط داخلي لا تحتاج قواعد إعادة كتابة.

1. من **Settings → Pages → Build and deployment → Source** اختر **GitHub Actions**.
2. رفع `main` يشغّل `.github/workflows/pages.yml`: تثبيت نظيف، اختبارات، فحص TypeScript وبناء، ثم رفع artifact ونشر Pages.
3. يمكن تشغيل المسار يدوياً من **Actions → Build, test and deploy Pages → Run workflow** بعد تفعيل Pages.
4. عنوان النشر المتوقع عند نجاح النشر: `https://esraasaada.github.io/Organic-Chemistry/`. هذا عنوان متوقع؛ راجع رابط deployment في Actions للتحقق من الحالة الفعلية.

## الدقة العلمية وحدود التنفيذ

الصيغ العامة مقيدة بنطاقها: الألكانات المفتوحة CnH₂n₊₂؛ الألكينات المفتوحة بثنائية واحدة CnH₂n؛ الألكاينات المفتوحة بثلاثية واحدة CnH₂n₋₂. الصيغة وحدها لا تحدد المتماكب أو نوع الروابط. البنزين موضح كرنين وعدم تمركز إلكتروني، وليس جزيئاً يتنقل بين بنيتين.

المحاكاة تعليمية وآمنة وليست تجربة حقيقية أو قياسات فعلية أو تعليمات للعمل المخبري. نموذج الاحتراق يحفظ الذرات، ويفترض تحول H إلى ماء وتوزيع بقية O على CO₂/CO/C؛ لا يحاكي حركية اللهب أو كل النواتج. يتقيد منزلق الأكسجين بمجال هذا الافتراض. ماء البروم ليس اختباراً حصرياً للألكينات، وقد يشارك الماء في النواتج؛ تُذكر حدود تبسيط إضافة Br₂. الأسترة اتزانية والحفاز لا يغيّر ثابت الاتزان.

النماذج الثلاثية تعليمية؛ بعض الزوايا محددة هندسياً، والبناء الحر والإيثانول تقريبيان وليسا محسنين طاقياً. فحص التكافؤ للذرات المتعادلة المعتادة فقط، لا للأيونات والجذور الحرة. لا يوجد محرك ديناميكا جزيئية أو حساب طاقة أو تسمية عامة لأي مركب.

الصور الجزيئية ورسوم التجارب مولدة برمجياً. رسوم التطبيقات الحياتية رموز توضيحية وليست صوراً فوتوغرافية. خط Noto Sans Arabic عبر Google Fonts (SIL OFL) اختياري مع خطوط نظام بديلة. لا مفاتيح API أو أسرار في التطبيق. بيانات الطالب تبقى في LocalStorage لهذا المتصفح؛ قد تُحذف بمسح بيانات الموقع ولا تتزامن بين الأجهزة. يتطلب الحفظ PDF اختيار «حفظ بتنسيق PDF» في نافذة الطباعة.

## التحقق المنفذ وحدوده

تشمل الاختبارات موازنة C/H/O عبر الوقود وقيم الأكسجين، صحة نواتج الإضافة والأسترة، التكافؤ والتعرف البنيوي وتمييز المتماكبات، توزيع بنك الأسئلة وصحة المؤشرات، إنهاء اختبار كامل، فتح الألعاب الست وتشغيل التجارب الخمس، التنقل واستعادة الاسم وتفضيلات العرض من التخزين. `npm run build` يفحص TypeScript ويبني حزمة الإنتاج.

لم يكتمل الفحص البصري على هاتف/حاسوب أو اختبار WebGL الفعلي في بيئة العمل بسبب تعذر خدمة المعاينة (relay readiness timeout). اختبارات DOM لا تثبت جودة الرسم أو الطباعة في المتصفح. يجب فحص العرض والتدوير والتكبير وPDF على أجهزة العرض المستهدفة قبل اعتماد العرض الجامعي النهائي.

### حالة التسليم في بيئة التنفيذ

- نجحت الاختبارات الآلية الست والعشرون، ونجح بناء الإنتاج وفحص TypeScript.
- حُفظ التنفيذ في commit محلي. محاولة Git push إلى `main` أعادت 403، ومحاولة موصل GitHub لإنشاء شجرة المصدر أعادت `Resource not accessible by integration`. يلزم إصلاح صلاحية كتابة المحتوى وملفات workflows للتكامل قبل المزامنة.
- لم يتم نشر Pages أو التحقق من رابط حي. تظل خطوات تفعيله أعلاه مطلوبة بعد نجاح رفع الملفات.
